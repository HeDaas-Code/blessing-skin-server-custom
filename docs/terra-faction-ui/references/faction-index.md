## Selection rules

- Prefer the institution that owns the user's information and primary decision.
- Compare the selected family against the full global palette matrix on every invocation.
- Do not use a location merely because a character is present there.
- For Iberia/Aegir mixtures, use `iberia-nautical` only when voyage, coastline, vessel, archive, or maritime state owns the screen.
- For cross-faction work, select one structural owner and borrow one non-color trait from the secondary family.
- If no family fits, research first instead of forcing a recipe.
