# Application depth

Choose depth independently from faction and task.

| Level | Key | Transformation | Typical use |
|---|---|---|---|
| 1 | `minimal` | Identity layer | Existing products and dense tools |
| 2 | `moderate` | Shell and stage | Dashboards, portals, landing pages |
| 3 | `complex` | System-wide reconstruction | Launchers, game-adjacent consoles |
| 4 | `maximal` | Bespoke experiential system | Event microsites and flagship showcases |

## 1 / minimal / 极简

- Preserve information architecture and most component structure.
- Apply faction tokens, type contrast, rule geometry, visible focus, and one strong state cue.
- Use zero or one persistent decorative system.
- Limit motion to direct feedback.
- Let the product read first and the faction second.

## 2 / moderate / 中等

- Recompose one shell region such as a rail, top bar, action strip, or title system.
- Use one or two coherent stage layers named by the faction recipe.
- Cover shared major controls while leaving low-priority utility UI near native conventions.
- Use one reveal family plus direct feedback; allow at most one restrained attention loop.
- Recompose portrait navigation and the primary action.

## 3 / complex / 复杂

- Transform the full shell into intentional operational zones.
- Use two to four meaningful faction instruments on the representative screen.
- Style the full shared component set: navigation, inputs, dialogs, menus, data surfaces, focus, selection, errors, and scroll states.
- Coordinate at least two motion families with reduced-motion parity.
- Re-art-direct desktop and portrait layouts.
- Make the experience a reconstructed system rather than a skin.

## 4 / maximal / 极繁

- Build bespoke compositions for major sections while retaining one global faction grammar.
- Use four to six coherent layers only where they carry state or narrative.
- Let route, mode, progress, selection, media, or verified data change the composition.
- Coordinate section transitions, masks, stage layers, and control feedback.
- Provide static reduced-motion and low-power fallbacks.
- Keep the primary action and current state faster to find than the decoration.

## Scorecard

Judge six axes holistically:

1. Shell transformation.
2. Stage layering.
3. Shared component coverage.
4. Truthful state instrumentation.
5. Motion coordination.
6. Responsive recomposition.

Increasing depth never permits fake telemetry, duplicate copy, extra accents, smaller essential text, weaker focus, or missing labels. A local screen may vary by one level when task density requires it; document the exception.
